Automated export sales platform, from raw ERP files to Power BI

Personal project for a fictional German exporter (9 countries, 7 currencies) · 2026

Challenge

ERP, CRM, budget and exchange-rate data arrive in different formats every day. Bad rows disappeared silently, foreign-currency revenue was converted inconsistently, and customer segment changes rewrote history.

Approach

YAML data contracts that auto-fix, quarantine or load every row; an incremental star schema with SCD Type 2 customers and live ECB rates, written as Delta tables for Fabric OneLake; and a Power BI model built as code with 43 DAX measures, a time-intelligence calculation group and dynamic row-level security.

Result

Runs every morning with no manual step: load, test, refresh, publish, deploy. It surfaced that discounts push distributor margins down to 34% and that the new US and Japan markets beat their budgets while Europe lags.

Challenge

Sales, budget and machine data sat in 5 systems: ERP exports from 7 branches, ERP master data, CRM, the controlling budget and MES. Sales, controlling and plant management had no common view.

Approach

Parameterised Power Query connectors, cleaned duplicates, encodings and German number formats, then modelled a star schema with 3 fact tables at different grain (daily sales, monthly targets, shift-level production) and 4 shared dimensions. Row-level security by branch.

How I work

From a business question to a report people use

  1. Understand the question

    Talk to the people who will use the report. What decision does it support, and how often?

  2. Integrate and clean

    Connect the sources, fix duplicates, formats and gaps, and write the checks down.

  3. Model the data

    A star schema at the right grain, so numbers add up the same way everywhere.

  4. Define the measures

    KPIs with clear, documented logic, so sales and controlling agree on what "margin" means.

  5. Deliver and hand over

    Focused report pages, access rules and version control, so the team can own it after me.
